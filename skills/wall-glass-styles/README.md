# Wall, glass and behind-the-head styles (free, not Vibha's paid pack)
Install: `bash install.sh`. Preview of the main looks: `preview.jpg`.

## Text on the walls
| Style | Skill folder | Notes |
|---|---|---|
| wall-perspective-text | text-effects-40 `/video-style wall-perspective-text` | Words painted on left/right walls of a corridor/room, recede to the vanishing point. Needs a room/corridor shot; set perspective-origin = vanishing point, wall lines from your frame. Locked-off shot best. |
| wall-projection-words | text-effects-40 `/video-style wall-projection-words` | Words slam onto a tilted wall, one per beat. Pure motion graphic. |
| huge-strike / profile-wall / headline-wall | reel-effects-55 | Big word on the wall behind you, crossed out; reels grid on the wall. |
| photo-burst | effectswithclaude | Polaroids slap onto the wall behind you. |
| Real 3D camera-solved wall text (handheld push-in) | none free yet | Use a tripod shot, or DaVinci Resolve Planar Tracker. |

## Liquid / frosted glass
| Style | Skill folder |
|---|---|
| glass-widgets (stat cards around head, one behind) | effectswithclaude, facecammaxxing, reel-effects-55 |
| glass-graph / liquid-glass-graph (look=bento) | facecammaxxing, reel-effects-55 |
| liquid-glass cards + karaoke captions | yuv-viral-video (HyperFrames, real backdrop-filter) |
| liquid-glass motion intro + kinetic subtitles | liquid-glass-motion-intro |
| HyperFrames blocks: vfx-liquid-glass, liquid-glass-widgets, liquid-glass-notification, glass-hero, glass-shard-title | `npx hyperframes add <name>` |
| Libraries for a custom glass caption pill | liquidGL (MIT), @ybouane/liquidglass (MIT) |

## Text behind the head
text-behind / backdrop-word (facecammaxxing), giant-word-behind + kinetic-captions (effectswithclaude), caption-parallax-layers (HyperFrames), text-effects-40 depth styles.
