# Open caption styles (not Vibha's paid pack)

Install: `bash install.sh [folder]` → HyperFrames caption blocks land in `<folder>/compositions/components/`.

## HyperFrames caption blocks (Apache-2.0, `npx hyperframes catalog --tag captions`)
| Block | Look | Good for |
|---|---|---|
| caption-parallax-layers | 3D text layered BEHIND the subject | hook word behind head |
| caption-editorial-emphasis | two fonts, huge emphasis word | biography / emotional |
| caption-weight-shift | elegant font-weight change | poetry, Amrita-type reels |
| caption-highlight | red box sweeps behind active word | TikTok style |
| caption-pill-karaoke | pill with per-word colour | default reel captions |
| caption-kinetic-slam | one full-screen word, alternate entries | punchlines |
| caption-camera-follow | sentence written across a huge world | cinematic hook |
| caption-clip-wipe | left-to-right wipe per word | clean explainer |
| caption-texture | lava/marble/metal/wood/concrete/rock texture text | titles |
| caption-gradient-fill | gradient text, elastic bounce | AI tricks |
| caption-emoji-pop | stroked text + emoji squeeze | funny reels |
| caption-glitch-rgb | RGB split + scanlines | tech/AI |
| caption-matrix-decode | scramble then reveal | AI/tech |
| caption-neon-glow / caption-neon-accent | neon glow | night/tech |
| caption-particle-burst | keyword explodes into particles | climax word |
| mk-callout-highlight / inline-highlight | callout + inline marker highlight | key facts |

Text behind the speaker rules (HyperFrames captions reference): a big word reads best 30-55% covered by the head; re-lay out if a word is 80% covered; measure against the matte per caption window. Use it once per beat for the peak word only; ordinary lines stay on the front caption rail.

## Remotion libraries (MIT)
- remotion-captioneer: 14 styles: word-highlight, karaoke, typewriter, bounce, wave, glow, erase, pill, flicker, highlighter, blur, rainbow, scale, spotlight.
- remotion-subtitle: 14 templates: Bounce, Colorful, Explosive, Fade, Fire, Glitch, Glowing, Lightning, Neon, Rotating, Shake, ThreeDish, TiltShift, Typewriter.
